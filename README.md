# tg_care_bot

Запуск

```
cp .env.example .env
```

```
docker compose --env-file .env --profile bots up -d --build
```

Админка доступна на `http://localhost:18001/`. Это отдельное Bootstrap-приложение
с рабочим столом и очередями задач администратора, а не прокси Starlette-Admin.

Основные рабочие разделы:

- модерация и приглашение исполнителей;
- проблемные заказы и назначение исполнителя;
- жалобы, споры и обращения поддержки;
- платежи, возвраты и выплаты;
- запросы на удаление аккаунта;
- каталог услуг и бизнес-настройки.

Списки заказчиков, файлов и аудита оставлены как вспомогательный поиск. Все
изменения проходят application services backend, требуют CSRF-токен и пишутся
в административный аудит.
